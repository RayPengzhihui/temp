# 生产成本结转凭证生成工具

从生产成本明细表自动生成会计软件凭证导入文件（`.xls` 格式）。

---

## 文件说明

| 文件 | 说明 |
|------|------|
| `generate_voucher.py` | 主脚本 |
| `生成凭证.bat` | Windows 双击运行 |
| `生成凭证.command` | Mac 双击运行 |

---

## 使用前提

安装 Python 依赖：

```bash
pip install openpyxl xlwt
```

---

## 使用方法

### Windows

- 双击 `generate_voucher.py` 直接运行（需 Python 已关联 `.py` 扩展名）
- 或双击 `生成凭证.bat`

### Mac

- 双击 `生成凭证.command`（首次运行需右键 → 打开）

### 命令行

```bash
python generate_voucher.py 生产成本0713.xlsx
```

运行后按提示输入文件名（如 `生产成本0713.xlsx`），同目录下自动生成 `凭证.xls`。

---

## 数据来源规则

读取生产成本表的 **生产成本** Sheet，按 FR 列类型分两种处理：

| FR 列值 | 凭证ID | 借方金额列 | 贷方明细列 | 贷方科目行 |
|---------|--------|-----------|-----------|-----------|
| 结转 | 1 | AV 列 | AW–BP 列 | 第 5 行 |
| 售后运维费用 | 2 | DG 列 | DH–EA 列 | 第 5 行 |

其他 FR 值的行自动跳过。

---

## 凭证生成规则

| 分录 | 科目 | 摘要 | 金额 |
|------|------|------|------|
| 借方 | FT 列 | FS 列 | 按类型取 AV 或 DG 列 |
| 贷方 | 对应列范围第 5 行科目 | FS 列 | 各列金额 |

**输出格式（30列标准格式）：**

- 币种名称：人民币
- 凭证类别：转
- 会计年 / 会计期间 / 制单日期 / 凭证号 / 制单人：留空（导入时由系统填写）
- 项目大类编码：97
- 借方科目以 `66` 开头或等于 `6901` 时，不填项目核算字段
