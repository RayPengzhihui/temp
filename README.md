# 生产成本结转凭证生成工具

从生产成本明细表自动生成会计软件凭证导入文件（`.xls` 格式）。

---

## 文件说明

| 文件 | 说明 |
|------|------|
| `generate_voucher.py` | 主脚本 |
| `生成凭证.bat` | Windows 双击运行 |
| `生成凭证.command` | Mac 双击运行 |

---

## 使用前提

安装 Python 依赖：

```bash
pip install openpyxl xlwt
```

---

## 使用方法

### Windows

1. 将生产成本 Excel 文件放到脚本同目录下
2. 双击 `生成凭证.bat`
3. 按提示输入文件名，例如：

```
请输入文件名（如 生产成本0713.xlsx）：生产成本0713.xlsx
```

4. 同目录下生成 `凭证.xls`

### Mac

1. 将生产成本 Excel 文件放到脚本同目录下
2. 双击 `生成凭证.command`（首次运行需右键 → 打开）
3. 按提示输入文件名
4. 同目录下生成 `凭证.xls`

### 命令行

```bash
python3 generate_voucher.py 生产成本0713.xlsx
```

---

## 数据来源规则

读取生产成本表的 **生产成本** Sheet，筛选条件：

- `FR 列` = `结转`
- `AV 列` 有金额

---

## 凭证生成规则

| 分录 | 科目 | 摘要 | 金额 |
|------|------|------|------|
| 借方 | FT 列 | FS 列 | AV 列 |
| 贷方 | AW–BP 列（第5行 5001 开头科目） | FS 列 | 各列金额 |

**输出格式（30列）：**

- 币种名称：人民币
- 凭证类别：转
- 会计年 / 会计期间 / 制单日期 / 凭证号 / 制单人：留空（导入时由系统填写）
- 项目大类编码：97
- 借方科目以 `66` 开头或等于 `6901` 时，不填项目核算字段
